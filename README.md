# ذكِّرنـي — ودجت مواقيت الصلاة لسطح المكتب (ويندوز)

**الموقع:** https://mowshcashy.github.io/thakrani/ · **التحميل:** [أحدث إصدار](https://github.com/mowshcashy/thakrani/releases/latest)

تطبيق سطح مكتب خفيف يعرض مواقيت الصلاة اعتمادًا على **التقويم الرسمي السعودي — أم القرى**، مصمَّم لمستخدمي الكمبيوتر على شكل **ودجت** أنيقة + **أيقونة في منطقة الإشعارات** (بجانب الساعة) تعرض العدّ التنازلي للصلاة القادمة — أشبه بودجت الطقس في ويندوز.

## المزايا
- **وضعان للعرض:** «أقرب صلاة» (بطاقة كبيرة + عدّ تنازلي حيّ) و«كل الصلوات» (قائمة اليوم كاملة مع تمييز الصلاة القادمة).
- **أيقونة منطقة الإشعارات:** تُرسم ديناميكيًا لتُظهر الوقت المتبقّي، مع تلميح تفصيلي وقائمة سريعة (تغيير المدينة/العرض، تحديث، إعدادات، خروج).
- **اختيار المدينة (١١٩ موقعًا):** المناطق الـ١٣ الرسمية تُؤخذ مواقيتها **كما هي من واجهة أم القرى**، وكل **المحافظات** (مثل الجبيل، ينبع، الخبر، القطيف، الطائف، الأحساء، الخرج…) تُحسب بطريقة أم القرى من إحداثياتها و«تُثبَّت» على مواقيت منطقتها الرسمية بحيث يُضاف فقط الفارق الجغرافي الحقيقي (بضع دقائق). الافتراضي **مكة المكرمة**.
- **تنبيهات + أذان:** إشعار ويندوز عند دخول وقت كل صلاة (قابل للتفعيل لكل صلاة) مع تشغيل الأذان بنوعين: **أذان كامل** أو **تكبيرات فقط** (تتوقف عند الثانية ١٦)، وقابل للاستبدال بملفك الخاص.
- **الإقامة:** حدّد وقتها (٥/١٠/١٥/٢٠ دقيقة بعد الأذان)، واختر متى يُشغَّل الصوت: عند الأذان أو الإقامة أو كليهما، مع عدّاد إقامة يظهر في الودجت وتنبيه مستقل.
- **ودجت مصغّر ثابت شفاف:** شريط صغير جدًا (اختياري، مفعّل افتراضيًا) يظهر دائمًا في المقدمة ويعرض الوقت الحالي + الصلاة القادمة والعدّ التنازلي؛ قابل للسحب والإخفاء.
- **الأذكار:** حصن المسلم كاملًا (١٣٢ قسمًا، ٢٦٧ ذكرًا) مضمّن للعمل دون اتصال، مع عدّاد لكل ذكر حسب تكراره، و**تذكير دوري** بفاصل زمني يحدده المستخدم (١٥ دقيقة إلى ٦ ساعات) مع ساعات هدوء.
- **المصحف الكريم:** ١١٤ سورة و٦٢٣٦ آية بالرسم العثماني (رواية حفص) بخط Amiri Quran، مع بحث في نص المصحف، تكبير/تصغير الخط، وعلامة متابعة القراءة.
- **ودجت سطح المكتب:** بطاقة زجاجية على طراز ماك ترسو على سطح المكتب خلف نوافذك، تعرض مواقيت اليوم والعدّ التنازلي.
- **تشغيل تلقائي** عند بدء ويندوز، **تحديث تلقائي** عبر GitHub، ثيم فاتح/داكن تلقائي، تنسيق ١٢/٢٤ ساعة، ويعمل **دون اتصال** بالاعتماد على آخر بيانات محفوظة.

## مصدر البيانات
مواقيت الصلاة مأخوذة من **موقع أم القرى الرسمي** (نفس الواجهة التي يعرضها الموقع لزوّاره):
`https://umqserv.kacst.gov.sa/api/v1/Prayer/GetTodayPrayersForCities?lang=ar&format=24`
(تعطي مواقيت ١٣ منطقة + التاريخ الهجري/الميلادي). قائمة المواقع الكاملة (١١٩ بإحداثياتها) في [`assets/data/cities.json`](assets/data/cities.json)، وحساب المحافظات بطريقة أم القرى عبر مكتبة `adhan` — مطابقة لواجهة أم القرى في حدود دقيقة واحدة للمناطق.

> ملاحظة تقنية: يُستدعى هذا المضيف من العملية الرئيسية عبر `net.fetch` في Electron (شبكة Chromium) لأن خادم الواجهة يرسل سلسلة شهادة ناقصة، ويُرسَل مع الطلب ترويسات متصفّح (User-Agent/Origin/Referer) لتفادي رفض البوّابة. التفاصيل في [`src/main/prayer-service.js`](src/main/prayer-service.js) و[`src/main/state.js`](src/main/state.js).

## التشغيل (للتطوير)
```bash
npm install
npm run assets     # توليد الأيقونات وصوت الأذان الافتراضي
npm start
```

اختبار طبقة البيانات فقط (دون واجهة):
```bash
node scripts/test-data.js "الرياض"
```

## بناء المُثبِّت (exe)
```bash
npm run build
```
النتيجة: `dist/Thakkerni-Setup-1.0.0.exe` (مُثبِّت NSIS) و`dist/win-unpacked/` (نسخة غير مغلَّفة).

> إن ظهر خطأ «Cannot create symbolic link» أثناء أول بناء، فعّل **وضع المطوّر (Developer Mode)** في ويندوز أو شغّل الطرفية كمسؤول (المشكلة من فكّ ضغط أدوات توقيع macOS غير المستخدمة على ويندوز).

## صوت الأذان
المضمّن: `assets/audio/adhan-full.mp3` (أذان كامل) و`assets/audio/adhan-takbeer.mp3` (أول ١٦ ثانية). يُختار النوع من **الإعدادات ← الأذان ← نوع الأذان**. لاستخدام ملفك الخاص: **الأذان ← اختيار…**.

## ملاحظة عن «شريط المهام»
لا يمكن لأي تطبيق طرف‑ثالث الحقن داخل شريط مهام ويندوز 11 أو لوحة الودجت (مكان الطقس) — هذا قيد من مايكروسوفت. لذلك يستخدم التطبيق **منطقة الإشعارات بجانب الساعة** (أقرب مكان دائم الظهور) مع الودجت العائمة.

## البنية
```
src/main/        العملية الرئيسية (بيانات، نوافذ، tray، مجدول، تنبيهات، IPC)
src/preload/     جسر آمن (contextBridge)
src/renderer/    الواجهات: widget، settings، tray-render (خلفية)، shared
assets/          الخطوط، الأيقونات، الصوت
scripts/         توليد الأصول + اختبار البيانات
```

## المصادر
- **المواقيت:** التقويم الرسمي السعودي — أم القرى.
- **الأذكار:** حصن المسلم (hisnmuslim.com).
- **المصحف:** الرسم العثماني — رواية حفص عن عاصم (مجمع الملك فهد لطباعة المصحف الشريف).
- **خط المصحف:** Amiri Quran — رخصة SIL OFL.

لإعادة بناء ملفات المحتوى: `node scripts/build-content.js`
